# DecodeLabs AI - Project 1: Rule-Based Chatbot

A deterministic, rule-based AI chatbot built as part of the DecodeLabs Internship Foundation Phase. 

## Features
* Continuous `while` input loop.
* Case and whitespace normalization/sanitization.
* $O(1)$ constant-time lookup using Python dictionaries.
* Fallback handler for unknown inputs.
* Clean exit strategy.
